# Learning notes — Indian-market AI trading sweep

Collected 22 November 2026 from X and the linked repositories. One row per strategy or operational lesson found in the second sweep, in the shape of [`../../../strategy-notes.md`](../../strategy-notes.md): setup, reported evidence, disclosed limits, source. Author-reported claims are marked **AR** and are not treated as verified results. Rows that change Foolshot's sizing, stops, costs, reconciliation, broker handling or SEBI/NSE compliance are flagged.

This file covers only what is **new** in this sweep. The strategies already in [`strategy-notes.md`](../../strategy-notes.md) are not repeated; the second live run by @pranjalsoni_ and the primary-source documents behind it are in [`../threads/`](../threads/).

## What the sweep changes for Foolshot

- **SEBI/NSE compliance (new, hard constraint).** Since 20 November 2026 an independent API trader must register a static IP, give the broker a written undertaking that they code their own algos, and forgo the exchange grievance route for losses caused by algo logic. Dhan is the primary broker; the account and IP plan must satisfy this before Day 1. See rows R1–R3.
- **Sizing.** Two independent sources point the same way: risk-based sizing with a per-trade rupee cap, a daily cap, and an explicit experiment size that cannot be raised mid-session. A skill pack's defaults are ₹500/trade and ₹1,500/day on a ₹50k budget (R18–R19); an author-reported record shows win rate and P&L are not the same thing (R26). An instruction to trade bigger on a hunch produced a losing day (R23), and an experimental scalp at ₹5 lakh per trade produced the largest reported loss in the captured run (R27).
- **Stops.** Stops must exist before entry and be broker-side where possible. Two failure classes are documented: a cancel-then-place sequence leaves a position naked (R12), and a single-IP rejection prevents an exit even when the stop is in the system (R5). Both need reconciliation and an out-of-band exit path.
- **Costs.** The skill pack ships a full NSE charge stack — ₹20/order, exchange transaction, SEBI turnover, STT, stamp duty, 18% GST, plus 0.15% equity and ₹0.50 option slippage (R15–R16). Foolshot should score net using a model of this shape and reconcile it against actual contract notes.
- **Reconciliation.** Broker positions are the source of truth on every restart, with a `bot_managed` flag so manual holdings are not adopted (R11). This matches the dossier's reconciliation requirement and needs a restart drill before launch.
- **Broker quirks.** Zerodha Kite MCP sessions reset daily and Kite MCP has had downtime/auth incidents (R7–R9). Dhan now exposes MCP, Skills and Cloud execution (R10), which is directly relevant to the Dhan-primary route. Order prices must be tick-rounded or the exchange rejects them instantly (R10b).
- **Market calendar.** NSE freeze limits changed from 2 November 2026 and Muhurat/timing updates shipped with the same release (R2–R4); a bot that hard-codes a stale holiday list can refuse to trade on a normal day (R24).
- **Data.** NSE now runs a free official MCP server (36 tools, cash market only, 1–3 minute delay, no F&O or intraday candles) (R29). A separate MIT-licensed MCP gives Claude live Screener.in/NSE data instead of stale model memory (R30). Both are research inputs, not execution feeds.
