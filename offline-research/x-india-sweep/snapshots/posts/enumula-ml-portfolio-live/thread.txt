My machine learning portfolio went from an empty repo to live in 2 days. 
Claude Code built it; I wrote the specs, handed over my project notebooks, and reviewed the entire process.

The stack:
1. .NET 10 MVC for the site
2. Models trained in Python (uv), exported to ONNX
3. ONNX Runtime serving predictions inside the app, with no separate Python API 

What Claude Code did: 
→ Turned each notebook into a reproducible train.py that writes the ONNX model, the form schema, the charts and test fixtures 

→ Built the metadata-driven site, so a new project is a folder and a JSON entry, with no new controller code 
→ Wired every model to a live form with schema validation and rate limiting 

→ Wrote parity tests that check the .NET output against scikit-learn\'s answers 

→ Wrote integration tests with WebApplicationFactory 

Live now: 7 Model Zoo projects with working forms, plus the flagship NSE market regime classifier (Nifty 200 + India VIX, walk-forward tested, illustrative). 

What made it work: 
1. A SPEC.md as the source of truth
